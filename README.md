# 🚗 Car Rental Management System

A full-featured web-based Car Rental Management System designed to
manage vehicles, customers, rentals, billing, employees and reports.

## 🌐 Live Demo

[Visit Live CarRentalManagement Website](https://carrentalmanagementwebpage.onrender.com/)

## ✨ Features

### Customer
- Browse available cars
- View car details
- Book a vehicle
- Submit rental information
- Return request functionality

### Admin
- Dashboard with statistics
- Vehicle management
- Customer management
- Rental management
- Billing
- Employee management
- Attendance management
- Reports
- Rental analytics

## 🛠️ Technology Stack

- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript
- Gunicorn
- Render
- GitHub

## 🗄️ Database

The system uses a MySQL relational database containing
tables for vehicles, customers, rentals, billing, employees,
attendance, reports and other system operations.

## 🔐 Security

Sensitive credentials and environment variables are kept outside
the public repository.
